### User Experience 1

Push (Pain)
- today actually forgot about syllabus details (finals date)
- used our app to check actual syllabus details to realize they got some dates wrong
- had to adjust entire schedule after learning this (this is a good thing because now its right)

Pull (Promise)
- wanted something that tells important information about a class like schedules
- potentially have reminders

Friction (Anxiety)
- if our friend hadn't mentioned something confusing about the finals schedule to us earlier, they might have just assumed our AI was wrong
- reasons:
  - it’s a project, built by students
  - she’s one of the first users
  - because it’s so new

Status Quo (Inertia)
- product already exists: canvas extension (BetterCampus) with a todo list on top/integrated into canvas
- said if this was a canvas extension she would use it
- still said she might actually use it because it scans through the syllabus, which BetterCampus does not

### User Experience 2
Push (Pain)
- when they don't know anyone in their classes, contacting peers is hard because people don't check their canvas inboxes, and discord links expire
- needed classmates contact but emails are hard to find, they normally just end up taking the L in these situations

Pull (Promise)
- expected maybe a calendar of class schedule, but not much expectation initially
- thought it had features that are very helpful
- better than canvas
- organized in a more user friendly, compact way
- specifically course agent was very helpful
- feels like it combines discord + a calendar + chatgpt

Friction (Anxiety)
- not really a fan of AI, but when they saw the AI output they trusted it because it used the information uploaded
- would be skeptical if it was some generic AI that didn’t have his information, but that's not the case here

Status Quo (Inertia)
- already bombarded with so much software, and this would be another thing you need to download
- said it would be better as an extension integrated into software we already use
